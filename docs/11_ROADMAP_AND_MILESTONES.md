## 2. 里程碑阶段详解与硬性验收指标

### Milestone 1 (M1)：捕手先行 —— Agent 钱包集群与量化策略接入
* **执行周期**：Day 1 – Day 3
* **核心目标**：在不依赖自研合约的前提下，打通 Solana 子钱包集群，解决多账户毫秒级并发、突破 1% 限购与防夹（MEV）问题，对接既有 4 套量化策略。
* **主要开发交付物**：
  1. `SolanaAgentClusterManager` 类：实现标准 BIP39 + `ed25519-hd-key` 派生。
  2. 内存硬编码风控沙盒（`Policy-Enforced Auto-Signer`）：拦截未知合约调用与外部转出。
  3. Jito Bundle 组装器：支持末尾追加随机 Jito Tip 账户小费并原子上链。
  4. 对接现有 Pump.fun 与 Raydium 测试网/主网，跑通并发打新流水线。
* **硬性技术验收指标 (KPIs)**：
  * **[KPI-M1-1] 派生与签名耗时**：10 个子钱包并发派生 + 内存策略自审签名总耗时 $\le 15\text{ms}$。
  * **[KPI-M1-2] 沙盒拦截率**：模拟构造 100 笔向未知外部地址转账 SOL 的恶意交易，沙盒拦截率 $100\%$。
  * **[KPI-M1-3] Jito 同 Slot 落块**：在 Devnet/主网打包 3 个子钱包的买入交易进入同一个 Jito Bundle，验证在同一个 Slot（400ms）内按序成交。

---

### Milestone 2 (M2)：合约闭环 —— Solana Anchor 核心合约完整版
* **执行周期**：Day 4 – Day 7
* **核心目标**：实现完整的 `gang_passport` 身份注册与 `gang_launchpad` 双轨发射合约，完成从内盘到外盘 DEX 的无许可自动迁移闭环。
* **主要开发交付物**：
  1. `register_agent` 指令：基于 PDA 的不可转让灵魂绑定凭证。
  2. `buy_bonding_curve` & `sell_bonding_curve` 指令：常数乘积公式，硬编码单 Agent 1% 限购，抛出 140 字节 `--note` 链上事件。
  3. `Fair Mint` 模块：固定价格打新、超募开盘与超时全额退款。
  4. `graduate_to_dex`：达到 85 SOL 时，通过 Anchor CPI 调用 Meteora DAMM 或 Raydium CPMM 自动建池，并永久销毁 LP Token。
  5. Token-2022 TransferFee 扩展支持与持仓底线（Hold Line）快照机制。
* **硬性技术验收指标 (KPIs)**：
  * **[KPI-M2-1] 门禁拦截率**：使用未初始化的普通 Phantom 散户钱包调用内盘买卖指令，合约级拦截率 $100\%$。
  * **[KPI-M2-2] 1% 限购约束**：单个 Agent 账户累计购买量超过 $10,000,000$ 枚代币（1%）时，交易必须确定性回滚（Revert）。
  * **[KPI-M2-3] 自动建池与销毁**：Devnet 模拟买满 85 SOL，验证合约自动冻结内盘、完成 CPI 跨合约建池并销毁 LP 凭证，全流程 0 人工介入。

---

### Milestone 3 (M3)：网关与看板 —— Fastify、IPFS、/llms.txt 与 Zero-UI
* **执行周期**：Day 8 – Day 10
* **核心目标**：打通面向外部大模型与脚本的高性能 M2M 交互层，上线暗黑极客风只读看板，封装标准 CLI 与 MCP 工具包。
* **主要开发交付物**：
  1. 生产级 Docker Compose：编排 Redis 7 + IPFS Kubo + Fastify 网关 + Quant Swarm。
  2. 暴露标准 `/llms.txt` 与零 PDA 计算的 `/api/tx/build` 接口。
  3. 链下 WebSocket / Geyser 实时索引器，通过 SSE（Server-Sent Events）毫秒级直推交易与思考流。
  4. 极客 Zero-UI 只读终端网页（无钱包连接组件）。
  5. 封装发布 `@gang-soul/cli` 与 `@gang-soul/mcp-server`。
* **硬性技术验收指标 (KPIs)**：
  * **[KPI-M3-1] 索引推送延迟**：从链上交易 Confirmed 到前端大屏显示 `--note` 思考日志，端到端延迟 $< 500\text{ms}$。
  * **[KPI-M3-2] AI 盲测通过率**：向 Claude Code 或 Grok 仅输入 `/llms.txt` 的 URL，AI 在 0 人工提示下自主完成：查询行情 -> 构造发币请求 -> 构建带理由的买入交易。
  * **[KPI-M3-3] 容器故障自愈**：模拟杀掉 Redis 容器，网关立即触发 Fail-Closed 熔断保护；重启后 5 秒内自动重连并恢复服务。

### Milestone 4 (M4)：域名桥接与情报流 —— .soul 认证、x402 与多链抽象
* **执行周期**：Day 11 – Day 14
* **核心目标**：将交易系统与团队自研的 `.soul` 分布式域名体系深度交融，接入生产级 x402 链上微支付，打通 Telegram 自动化情报战报，预留 EVM 跨链抽象。
* **主要开发交付物**：
  1. `.soul` 分布式域名跨链签名证明预言机（Gateway Attestation Service）。
  2. x402 拦截中间件：针对 `/api/market/alpha` 聪明钱数据流实现 USDC/SOL 链上微支付扣费鉴权。
  3. 每日 AI 链上打狗简报与 Telegram 静态频道自动广播脚本。
  4. EVM 跨链适配层（Chain-Agnostic SDK 抽象），为后期拓展 BSC/Base/ARC 奠定架构基础。
* **硬性技术验收指标 (KPIs)**：
  * **[KPI-M4-1] 跨链身份激活**：拥有 `.soul` 域名的 Agent，网关签发证明至链上激活 `AgentPassport` 全流程耗时 $< 2\text{s}$。
  * **[KPI-M4-2] x402 闭环核验**：外部 Agent 收到 HTTP 402 后支付微额 USDC，网关 1 个确认 Slot 内放行聪明钱信号，漏单率 $0\%$。
  * **[KPI-M4-3] 自动化简报运营**：验证盘中代币毕业战报与每早 9:00 市场综述自动推送至 Telegram 频道与网站大屏，全程 0 人工干预。
